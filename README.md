Asylum Chronicles
=================

Веб-версия игры: index.html — страница входа, game.html — сама игра.
Ассеты лежат в audio/ и fonts/, ролики — intro_*.mp4 и trailer_*.mp4.

Как выложить на GitHub Pages
----------------------------
1. Создайте пустой репозиторий на github.com (без README).
2. Распакуйте этот архив и загрузите ВСЕ файлы и папки в корень репозитория
   (Add file → Upload files → перетащите содержимое папки, а не саму папку).
3. Settings → Pages → Source: Deploy from a branch, Branch: main, Folder: / (root) → Save.
4. Через 1–2 минуты игра откроется по адресу https://<логин>.github.io/<репозиторий>/

Файл .nojekyll уже добавлен — без него GitHub Pages может не отдать часть файлов.

Локальная проверка
------------------
Открывать через file:// нельзя: браузер запрещает чтение audio/ с диска.
Запустите в папке игры любой http-сервер, например:

    python -m http.server 8000

и откройте http://localhost:8000/
